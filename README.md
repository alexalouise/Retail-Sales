# Retail-Sales
Beginner SQL analysis of retail sales transactions using PostgreSQL and pgAdmin.# Retail Sales Analysis (PostgreSQL)

## 📌 Project Overview
This project presents an end-to-end exploratory data analysis (EDA) of retail sales transactions using **PostgreSQL** and **pgAdmin**. The analysis covers customer demographics, purchasing patterns across product categories, profitability metrics, and time-of-day sales distribution to uncover actionable business insights.

---

## 📦 Project Includes
This repository contains all the necessary resources and source code to replicate the analysis:

* 📄 **`SQL_Retail_Sales_Analysis.csv`**: Raw dataset containing 1,987 customer transaction records across 11 attributes.
* 📜 **`retail_sales_analysis.sql`**: Complete SQL script featuring database schema setup, table definitions, data cleaning, and core analytical queries.

---

## 🛠️ Tools & Technologies Used
* **Database Management System:** PostgreSQL
* **Database GUI:** pgAdmin 4
* **Language:** SQL
* **SQL Concepts Applied:** 
  * Data Retrieval & Filtering (`SELECT`, `WHERE`, `LIMIT`, `DISTINCT`)
  * Data Aggregations (`COUNT`, `SUM`, `AVG`)
  * Grouping & Categorical Filtering (`GROUP BY`, `HAVING`)
  * Data Sorting (`ORDER BY`)
  * Custom Conditional Calculations (`CASE WHEN`)
  * Type Casting & Formatting (`CAST`)
